Getting started

Base URL: https://YOUR-BACKEND

  1. Open the API panel and press Generate key. Copy the key now, it is shown once.
  2. Find your server's docId. It is the ID in the panel URL, for example /<docId>/console.
  3. Send a POST request with a JSON body and the X-API-Key header.
curl -X POST https://YOUR-BACKEND/server_power \
  -H "X-API-Key: xtech12345678901" \
  -H "Content-Type: application/json" \
  -d '{"docId": "YOUR_SERVER_DOC_ID", "signal": "restart"}'

Every request is POST with Content-Type: application/json. Every body needs docId. Successful responses contain "ok": true.

Authentication

ItemDetails
HeaderX-API-Key: xtech12345678901
Key formatxtech followed by 11 digits
Keys per accountUp to 10
Allowed IPsOptional. Up to 20 addresses or CIDR ranges per key. Requests from other IPs are rejected.
AccessA key acts as your account. You can only do what you can do in the panel on that server, including the permissions an owner gave you.
Failed attempts15 bad keys in one minute from one IP is blocked with 429.

Keep keys private. If a key leaks, delete it in the API panel.

Errors

Errors return {"ok": false, "error": "message"} with an HTTP status.

{"ok": false, "error": "permission denied"}
StatusMeaning
400Missing or invalid field, or missing docId
401Invalid key or sign-in required
403Not allowed or permission denied for this server
413Storage limit reached
429Too many failed attempts
502 / 503The host panel is unreachable or still being set up
